##  오늘 공부한 내용 (4-2)

### 리스트 / index
- 리스트: 여러 개의 자료들을 모아서 하나의 묶음으로 저장한 것
- (ex) list = ['국어', '수학', '영어', '과학'] ==> 이런식으로 list란 묶음에 과목들을 넣는다.
- append함수: 리스트에 추가 가능 ==> list.append('사회') ==> list = ['국어', '수학', '영어', '과학', '사회']
- pop함수: 리스트에 삭제 기능 ==> list.pop(1) ==> list = ['국어', '영어', '과학'] ==> 파이썬은 0부터 숫자를 세기 때문에 '수학'이 빠짐

### index
- 문자열에서 개별의 문자를 추출하는 것에 index를 사용한다.
- (ex) s = python print(s[1 :5]) ==> ytho ==> 파이썬은 0부터 숫자를 세기 때문에, 5를 적는 것은 끝 번호의 문자는 포함이 안되기 때문
